## `//` WORKFLOW

<div align="center">

`LEARN` &nbsp;→&nbsp; `UNDERSTAND` &nbsp;→&nbsp; `BUILD` &nbsp;→&nbsp; `BREAK` &nbsp;→&nbsp; `DEBUG` &nbsp;→&nbsp; `IMPROVE` &nbsp;→&nbsp; `REPEAT`

</div>

<br/>

<table width="100%">
<tr><th align="left" width="20%">Stage</th><th align="left">What it means to me</th></tr>
<tr><td><code>LEARN</code></td><td>Studying the underlying concept before touching any code</td></tr>
<tr><td><code>UNDERSTAND</code></td><td>Making sure I know <i>why</i> something works, not just <i>that</i> it works</td></tr>
<tr><td><code>BUILD</code></td><td>Applying the concept in practice</td></tr>
<tr><td><code>BREAK</code></td><td>Pushing the implementation until something fails</td></tr>
<tr><td><code>DEBUG</code></td><td>Tracing the failure back to its root cause</td></tr>
<tr><td><code>IMPROVE</code></td><td>Refining the solution once it's understood properly</td></tr>
<tr><td><code>REPEAT</code></td><td>Carrying that process into the next concept</td></tr>
</table>
